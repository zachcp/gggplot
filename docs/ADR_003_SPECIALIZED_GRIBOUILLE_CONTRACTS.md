# ADR 003: Specialized Gribouille contracts

Status: accepted, 2026-07-18

## Context

The pinned comparison source is
`mcanouil/gribouille@03dbfde6d3a578741b7e66f62c3c184bf41191ad`, captured in
`GRIBOUILLE_03DBFDE6_GALLERY.yml`. These examples are useful design references,
but they are not automatically base-ggplot2 parity. A feature belongs in core
only when its data product is backend-independent, serializable, and useful
beyond one source example.

The user explicitly rejected Typst text. gggplot will not add a Typst evaluator,
Typst markup geom, or implementation bead.

## Consequences

- Streamgraph and bump remain compositions of reusable core grammar primitives
  rather than bespoke geoms; waffle is a bounded core stat over tile rendering.
- Cluster marks use the existing portable extension registry and do not expand
  core `GeomKind`.
- Typst strings are never evaluated. They may only be displayed as ordinary
  literal text if supplied to `geomText`.
- Each accepted implementation has its own bounded bead and executable
  acceptance criteria. This ADR makes no implementation claim.
