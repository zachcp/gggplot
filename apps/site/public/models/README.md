# Bundled ONNX smoke model

mnist-12.onnx is the small MNIST classifier from the ONNX Model Zoo, mirrored
from the onnxmodelzoo/mnist-12 Hugging Face repository.

- License: Apache-2.0
- Source: https://huggingface.co/onnxmodelzoo/mnist-12
- Runtime target: ONNX Runtime Web
- Input: Input3, float32, [1, 1, 28, 28]
- Output: Plus214_Output_0, float32, [1, 10]
- SHA-256: 5c688690f8bacf667d4c2074af5ad0646ca328d7ab03eccf944a65b320171bdd

The docs page also includes three small synthetic ONNX topology fixtures. They
are generated by `scripts/generate_model_layout_fixtures.ts`, are not intended
for inference, and exist solely to compare 3D graph layouts:

- `dense-chain.onnx` — sequential MLP-style chain.
- `residual-merge.onnx` — parallel residual branches that merge at `Add`.
- `multi-head.onnx` — shared stem, three heads, and a fan-in `Concat`.
- `tiny-encoder-stack.onnx` — two attention-like encoder blocks with residual
  and feed-forward stages (50 graph nodes, 57 edges).

The file-picker remains available for trying another local ONNX file.
